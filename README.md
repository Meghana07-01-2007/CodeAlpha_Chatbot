# CodeAlpha Basic Chatbot

A simple rule-based Python chatbot developed as part of my CodeAlpha Python Development Internship.

## 📌 Project Overview

This project is a basic conversational chatbot that accepts user input and provides predefined responses based on the entered message.

The chatbot can respond to greetings, simple questions, and goodbye messages.

## ✨ Features

- Responds to greetings such as hello, hi, and hey
- Responds to "how are you"
- Provides its name and capabilities
- Handles unknown inputs
- Continues the conversation until the user exits
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Functions
- `if-elif-else`
- `while` loop
- User Input and Output
- String Handling
